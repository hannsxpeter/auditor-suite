# Ledgerly

Expense reports and approvals for small teams. Employees photograph a
receipt and submit the expense in under a minute; an approver on the team
approves or returns it; approved expenses are paid with the next payroll run.

Ledgerly is a public SaaS product. New teams start a 14-day free trial from
the sign-up page and then pay per member. The person who signs up owns the
team account and invites everyone else.

## Develop

```
npm install
npm run dev      # the web app on :5173
npm run server   # the API on :3000
```
