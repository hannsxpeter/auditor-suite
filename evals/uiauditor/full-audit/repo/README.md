# Lumen Store web

The storefront for Lumen Store, a public online shop for outdoor clothing. It is
a React single-page app built with Vite and Tailwind CSS, served to every
customer at `shop.lumen-store.example`: the landing page, the product grid, the
cart, and checkout.

## Run

```
npm install
npm run dev
```

Design tokens live in `src/styles/tokens.css` and are mapped into Tailwind in
`tailwind.config.js`. Product and campaign images are served from the image CDN
at `cdn.lumen-store.example`.
